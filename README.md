# 📱 사회초년생 맞춤형 자립 지원 플랫폼

사회에 첫발을 내딛는 청년 및 사회초년생을 위한 **주거·자산·취업 통합 가이드 모바일 애플리케이션**입니다.

---

## 🚀 주요 기능 (Features)

### 🏠 주거

* 기본 용어 설명
* 방 구하기 체크리스트
* 계약서 팁
* 트러블슈팅 가이드

### 💰 자산

* 청약 가이드
* 정부지원금

### 💼 취업

* 근로계약서 가이드
* 주요 구직사이트

### 🤖 AI 챗봇

* 청년 정책 및 계약 관련 질의응답
